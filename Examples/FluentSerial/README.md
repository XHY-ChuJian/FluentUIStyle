# FluentSerial - 现代 FluentUI 串口调试与嵌入式协议工作台

FluentSerial 是一款完全基于 **Qt6 + FluentUI3Style + ExWidgets** 开发的高颜值、无广告、纯原生、现代 WinUI3 风格的专业串口调试与嵌入式协议工作台。

---

## ✨ 主要功能与特性

### 1. 📡 基础收发监控 (Console / Monitor)
- **高性能双向接收**：支持 ASCII 文本与 HEX 十六进制实时展示与转换；
- **毫秒高精度时间戳**：`[14:20:05.123] [Rx/Tx]` 分色高亮排版；
- **防卡顿节流缓冲区**：针对 115200~921600+ 高速数据流进行异步分批缓冲合并，彻底告别界面卡顿；
- **一键追加校验码**：支持在发送 HEX/文本内容时自动计算并追加 CRC16 Modbus/CCITT、CRC32、Sum8 累加和或 XOR 校验码；
- **日志导出**：支持一键将接收数据导出保存为 `.txt` / `.log` 文件。

### 2. ⚡ 多指令快捷面板与自动化 (Quick Commands & Automation)
- **多指令配置表格**：支持对数十条预设指令配置备注名称、HEX/文本模式、内容、单条发送按钮与延时间隔；
- **自动化序列调度器**：支持一键【单次顺序执行】或【定时循环轮询执行】，并提供实时进度指示；
- **配置导入导出**：支持将所有预设指令导出为标准 JSON 配置文件，方便在不同单片机、传感器、PLC 项目之间快速切换。

### 3. 📈 实时多通道波形示波器 (Oscilloscope / Waveform)
- **多通道动态曲线**：支持 1~8 个通道实时折线绘制；
- **文本自适应解析**：自动匹配串口中以逗号、空格或换行分隔的数值流（如 `12.5, 45.8, -3.0` 或 `ch1:100 ch2:200`）；
- **全方位控制**：支持动态量程自适应、水平采样深度（100~1000点）调整、通道隐藏/重命名/调色、暂停与清屏；
- **内置模拟数据发生器**：即使未连接真实硬件，点击【模拟正弦波演示】即可立即体验流畅波形绘制。

### 4. 🧮 嵌入式协议与计算工具箱 (Protocol & Calc Toolbox)
- **CRC 与校验码计算器**：即输即算 CRC16 (Modbus 高/低位优先、CCITT、XMODEM)、CRC32、Sum8、Sum16、XOR (BCC)、LRC；
- **IEEE-754 浮点转换**：单精度 Float ↔ 32 位 HEX 双向即时转换（支持大端 Big-Endian 与小端 Little-Endian）；
- **Modbus RTU 快速组帧器**：从站地址、功能码 (01H~06H, 10H)、起始地址、数量一键组装带校验的完整 HEX 报文，并支持直接发送至串口。

### 5. 🎨 现代 WinUI3 视觉与深浅色主题
- 全局常驻串口控制器与端口热插拔自动检测；
- FluentWindowFrame 磨砂玻璃无边框窗口与自适应侧边栏导航；
- 完美支持深色 (Dark) / 浅色 (Light) 主题无缝切换。

## 🛠️ 构建与运行

```bash
# 使用 CMake 与 Ninja 构建 FluentSerial 目标
cmake --build build --target FluentSerial

# 运行程序
./build/bin/FluentSerial.exe
```
